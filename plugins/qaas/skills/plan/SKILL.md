# Plan

Invoke the hidden plugin skill `qaas:qaas-workflow` (directory `qaas-workflow`) with:

- `phase`: `plan`
- `provenance`: `manual:/qaas:plan`
- `arguments`: `$ARGUMENTS`

Do not reinterpret the phase or permit project implementation while the plan is being discovered or reviewed.
